Key Industrial Decisions

Why ResNet-18?

Residual skip connections eliminate the vanishing gradient problem while maintaining an ultra-light 11.2M parameter footprint. Inference completes in under 15ms on standard CPU hardware without GPU accelerator requirements.

Why WeightedRandomSampler?

Real-world wafer datasets (like WM-811K) are heavily imbalanced with >60% normal wafers. Instead of using excessive loss weights that risk class collapse, we balance mini-batch sampling directly in the PyTorch DataLoader.

Stratified Lot/Time Split

Guarantees every minority defect class appears in both training and validation sets, preventing the synthetic "lucky split" phenomenon and ensuring honest macro-F1 evaluation.

Sub-Die Grad-CAM Explainability

Takes gradients of the target class score with respect to Layer4 feature activation maps to compute spatial attribution overlays without modifying the network architecture.
